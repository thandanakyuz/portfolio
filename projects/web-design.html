Overview

The project involved designing and constructing a website for the official School of Applied Languages department at Bilkent University using HTML and CSS, completed as part of an undergraduate course in Translation and Interpretation. The course was instructed by Erin Maloney and supervised by Dr. Nihat Solakoğlu (Department of Banking and Finance).

Tools & Techniques

  • HTML
  • CSS
  • Notepad++

The dropdown menu component was adapted from a CodePen snippet by Little Snippets. The image slider was built using Imageslidermaker.
